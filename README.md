🧮 Calculadora React

Uma aplicação web de calculadora desenvolvida com React, Vite e CSS Modules. O projeto conta com uma estrutura organizada em componentes, interface responsiva e lógica de formulário dedicada.

🚀 Tecnologias Utilizadas

React: Biblioteca JavaScript para criação de interfaces de usuário.

Vite: Ferramenta de build rápida e moderna para desenvolvimento web.

CSS Modules: Estilização encapsulada por componente, evitando conflitos de classes globais.

JavaScript (ES6+): Lógica da aplicação.

ESLint: Garantia de padronização e boas práticas no código.

✨ Funcionalidades e Destaques

🧩 Arquitetura Componentizada: Lógica e formulário da calculadora isolados no componente FormCalculadora.

💅 Estilização Modular: Uso de FormCalculadora.module.css para manter o CSS organizado e escopado.

⚡ Alta Performance: Projeto construído com Vite para inicialização e hot-reload ultrarrápidos.

📱 Interface Adaptável: Layout pronto para exibição em diferentes tamanhos de tela.
